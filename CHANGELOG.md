## [Unreleased]

### Added
- Initial beta release
- Java, Kotlin, JSON and XML-based language support
- Configurable maximum pinned lines
- Click-to-navigate on pinned headers
- Initial scaffold from [IntelliJ Platform Plugin Template](https://github.com/JetBrains/intellij-platform-plugin-template)
